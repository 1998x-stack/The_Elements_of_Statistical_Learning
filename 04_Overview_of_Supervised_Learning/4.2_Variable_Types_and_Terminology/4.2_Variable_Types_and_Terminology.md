# 4.2 Variable Types and Terminology（变量类型与术语）

- **定量变量**：实值（如收入、温度）。
- **定性变量（类别 / 因子）**：取值于离散集合，常用 **one-hot / 哑变量**编码为 0-1 向量。
- 记号：输入 $X$（$p$ 维）、输出 $Y$，共 $N$ 个观测。

## 公式

one-hot 编码：$\phi(x)\in\{0,1\}^K$，$K$ 为类别个数。
