# 13.7 Example: ZIP Code Data（手写数字 ZIP 数据示例）

## 内容

书中用美国邮政的**手写数字 (ZIP)** 图像展示神经网络分类：把高维图像输入（如 $16\times16$ 灰度）经隐藏层后作多重输出（10 个数字类，softmax）。

- 这里用 sklearn `digits`（$8\times8$）作代理演示。

## 关键点

- 高维输入下网络自动学习特征组合；
- 输出用 softmax 给各数字类的概率。

## 代码示例

- 运行 `13.7_...py`：在 digits 上训练 MLP 并打印测试准确率。
