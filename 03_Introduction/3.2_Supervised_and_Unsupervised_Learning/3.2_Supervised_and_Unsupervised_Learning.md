# 3.2 Supervised and Unsupervised Learning（监督与无监督学习）

## 内容

- **监督学习**：样本 $(x_i,y_i)$ 带标签，学习 $\hat f$ 使 $\mathbb{E}[L(Y,f(X))]$ 最小——回归、分类。
- **无监督学习**：只有 $x_i$、无标签，任务是发现结构：聚类、降维、密度估计、关联规则。

## 核心概念

监督学习根植于风险最小化；无监督常借助数据的几何 / 概率结构（如高斯混合、流形假设）。
