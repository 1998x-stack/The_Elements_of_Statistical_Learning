# 6.3 Linear Discriminant Analysis（线性判别分析）

## 内容

LDA 假设各类数据服从高斯分布、均值 $\mu_k$ 不同但**协方差相同 $\Sigma$**。由贝叶斯规则，分到使后验最大的类 $k$，等价于最大化**线性判别函数**：

$$
\delta_k(x)=x^T\Sigma^{-1}\mu_k-\tfrac12\mu_k^T\Sigma^{-1}\mu_k+\log\pi_k
$$

因为二次项 $-\tfrac12x^T\Sigma^{-1}x$ 与 $k$ 无关，所以 $\delta_k$ 是 $x$ 的**线性**函数，类别间边界为超平面。

## 相关话题

- 降维：判别式方向（Fisher 判别）把数据投影到 $K-1$ 维；
- 正则化：实际使用样本协方差 $\hat\Sigma$，必要时加岭正则（RDA）。
