# 9.8 Minimum Description Length（最小描述长度）

## 内容

**MDL** 把模型选择视为"数据压缩"：总描述长度 = 编码模型的长度 + 编码残差的长度。选使总长最短的模型：

$$
\mathrm{MDL}:\quad \min_{M}\big[\,\text{描述模型 }M \text{ 的位数} + \text{描述用 }M \text{ 的残差的位数}\,\big]
$$

与 BIC 等价（对连续参数）——都体现"奥卡姆剃刀"。

## 关键点

- 正则化可看作数据先验编码长度的体现；
- 选复杂模型能降低残差编码但抬升模型描述成本，二者折衷。
