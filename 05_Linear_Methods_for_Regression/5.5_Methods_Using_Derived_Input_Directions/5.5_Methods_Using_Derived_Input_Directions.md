# 5.5 Methods Using Derived Input Directions（使用派生输入方向的方法）

## 内容

先用无/有监督方式把 $p$ 个输入压缩为少数几个"派生方向"，再对投影做回归：

- **主成分回归 PCR**：取 $X$ 的前 $K$ 个主成分方向，再线性回归。主要利用了 $X$ 的结构（方差）。
- **偏最小二乘 PLS**：在选取方向时同时考虑与 $y$ 的相关性，每个方向都在上一个方向的正交补内最大化与 $y$ 的协方差。

## 公式

PCR 的派生输入为 $\hat z_m=X v_m$（$v_m$ 是 $X$ 的第 $m$ 个右奇异向量/主成分方向），然后

$$
\hat y_{\mathrm{PCR}} = \bar y + \sum_{m=1}^{K}\hat\theta_m\,z_m
$$

## 权衡

投影到低维方向能大幅降低方差，尤其在 $p$ 大、变量高度相关时；但若真实信号方向与主成分方向不一致，会引入偏差。
