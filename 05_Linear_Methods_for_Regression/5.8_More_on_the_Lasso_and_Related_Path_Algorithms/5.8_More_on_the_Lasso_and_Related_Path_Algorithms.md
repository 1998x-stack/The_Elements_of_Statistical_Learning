# 5.8 More on the Lasso & Related Path Algorithms（Lasso 的更多内容与路径算法）

## 内容

Lasso 解随正则化参数 $\lambda$ 变化形成**路径**：$\lambda$ 增大时，系数被"软阈值"逐个压至精确零。高效求解方法包括：

- **LARS（最小角回归）**：从零开始逐步加入变量，沿路径更新，$O(np^2)$ 计算可得到整个路径；
- **坐标下降 / glmnet**：对高维问题有效，逐个坐标优化。

## 关键点

- L1 罚＝软阈值算子 $\mathrm{soft}(z,\gamma)=\mathrm{sign}(z)(|z|-\gamma)_+$，这是 Lasso 得**精确零解**的根源。
- Lasso 与 MCP、Elastic Net 等衍生。
