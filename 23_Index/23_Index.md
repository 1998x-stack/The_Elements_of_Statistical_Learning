# 23 Index（索引）

本章是全书概念、术语与符号的字母索引，指向出现这些概念的具体章节/页码。作为 back-matter 索引，它是读者在读完正文后回溯概念位置的检索工具。

## 说明

- 索引按术语字母顺序排列，标注对应的章节区间（如 *Lasso* → 第 5.4 节）。
- 常与 `22_Author_Index`、`21_References` 配套使用。
