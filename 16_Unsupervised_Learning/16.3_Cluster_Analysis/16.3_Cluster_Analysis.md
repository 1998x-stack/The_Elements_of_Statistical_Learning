# 16.3 Cluster Analysis（聚类分析）

## 内容

把样本分成（尽量）同类相聚的若干组。主要类别：

- **基于划分**：k-means（优化平方距离和）；
- **层次法**：凝聚 / 分裂，得到树状图；
- **基于模型**：高斯混合（8.8）。

k-means 目标：

$$
\min_{\{C_k\}}\ \sum_{k=1}^{K}\sum_{i\in C_k}\|x_i-\mu_k\|^2
$$

## 关键点

- $K$ 的选择多用肘法 / 间隙统计 / 交叉验证；
- 结果依赖初始化与距离度量。
