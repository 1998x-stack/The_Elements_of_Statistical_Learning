# 16.7 Independent Component Analysis & Exploration (ICA 与探索性投影寻踪)

## 内容

**ICA** 在"观测 = $A\times$独立源"假设下恢复**统计独立**的信号（盲源分离）：

$$
X = A\, S,\qquad S_i \text{ 相互独立}
$$

利用源的**非高斯性**，通过最大化"非高斯度"找到独立方向。

**探索性投影寻踪 (EPP)**：在数据中找到投影方向，使某准则（峰度、非高斯量）最大，用于降维可视化。

## 关键点

- 与 PCA 只去相关不同，ICA 追求**独立**（更高阶）；
- 源假设非高斯才可能可辨识。
