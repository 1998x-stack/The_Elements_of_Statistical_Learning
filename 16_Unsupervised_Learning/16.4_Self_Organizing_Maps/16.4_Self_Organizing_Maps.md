# 16.4 Self-Organizing Maps（自组织映射，SOM）

## 内容

**SOM / Kohonen 网络**用一个**低维网格**的原型近似高维数据，并保持**拓扑**：

- 每个网格单元有原型权重；
- 学习时更新"赢家"及其拓扑邻居的原型；
- 结果是数据的低维"地图"，邻近单元对应相近数据。

## 关键点

- 与 k-means 类似但强调保持邻域拓扑；
- 用于可视化与原型提取。
